# Interface languages

English, Estonian, Russian, Brazilian Portuguese, Spanish, German, French, Finnish, Ukrainian, Latvian, Lithuanian and Polish apply across the React interface, including portals, menus, form descriptions, placeholders and accessible labels. `languages.ts` owns the frontend codes, native labels and date locales. SettingsController validates the same codes. Changing Language & Time previews immediately and saves account preferences with a keepalive request. Room overlays notify the parent immediately and refresh its account preferences after saving.

`resources/js/lib/localizedReact` is the JSX runtime. It localizes text through React without rewriting the DOM, while preserving refs, cloned element props, input values and existing component state. The Vite user-content transform marks user names, chat messages, room names and track metadata as original text. Code examples and language autonyms are also excluded. A component requiring literal string children can opt out with `Component.originalText = true`.

The shipped catalogs are static and need no translation service or credentials. Only the selected non-English catalog loads; English needs no dictionary. The initial selected language loads before the first app render, and switching language updates already mounted text when its dictionary arrives. Reviewed product wording is in `resources/js/lib/locales/overrides.ts` (Estonian/Russian) and `expandedOverrides.ts` (new languages, with Brazilian Portuguese wording). Dynamic sentences use numbered placeholders such as `{0}`. Add user-content exclusions with the transform when introducing new content fields.

Catalog authoring scripts extract source messages and can generate an offline baseline with [Argos Translate](https://github.com/argosopentech/argos-translate), its English–Estonian and English–Russian 1.9 models, CTranslate2 and SentencePiece. These tools are not needed to build or run the website. Run `python scripts/prepare-translation-tools.py` to create the ignored `.tmp/translation-tools` cache before generating baseline catalogs. The extraction scripts recreate `tmp` for their own output. Review new translations in the overrides file, especially product terminology and short labels.

For additional languages, pass their codes to `python scripts/prepare-translation-tools.py pt-BR es de fr fi uk lv lt pl`. Model links come from the official Argos package index; `pt-BR` uses the English-to-Portuguese model with the reviewed Brazilian wording applied at runtime. The isolated Python 3.12 tools require CTranslate2, SentencePiece, NumPy, PyYAML, Sacremoses and subword-nmt. The authoring scripts support both SentencePiece and Moses/BPE packages. Models and tools stay outside the shipped application, in the ignored `.tmp/translation-tools` folder.

After generation, run `python scripts/normalize-locales.py` to remove residual tokenizer markers, keep SVG data literal, apply Brazilian terminology and reject damaged placeholders. This step uses only Python's standard library.

Model provenance: [Argos package index](https://github.com/argosopentech/argospm-index). Portuguese, French, Finnish, Latvian, Lithuanian and Polish packages credit Jörg Tiedemann and Santhosh Thottingal, “OPUS-MT — Building open translation services for the World”, EAMT 2020, and identify the original OPUS models as CC-BY 4.0. The Spanish package credits the OPUS OpenSubtitles, ParaCrawl and UNPC corpora. The Ukrainian package credits OPUS, Wiktionary/Wiktextract, WikiMatrix and CCAligned. Package versions used: Portuguese/French/Finnish/Latvian/Lithuanian/Polish 1.9, Spanish 1.0, German 1.3, Ukrainian 1.4. Static translations were generated offline and core product wording was edited separately.

Checks: frontend tests cover optimistic state, original text protection, dictionary coverage and placeholder preservation for every new language. Browser scenarios cover immediate switching, navigation, original user content, Discord on public/auth pages, permission controls, Brazilian Portuguese and Russian mobile settings. They use the disposable browser fixture database.
