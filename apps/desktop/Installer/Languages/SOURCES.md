# Installer translations

Most languages use the translations supplied with the pinned Inno Setup 7.1.0 compiler.
Estonian and Latvian are derived from the user-contributed files in the upstream Inno Setup repository:

- [Estonian](https://raw.githubusercontent.com/jrsoftware/issrc/f828fb0334106778f0aec21957af8e33dc468697/Files/Languages/Unofficial/Estonian.isl)
- [Latvian](https://raw.githubusercontent.com/jrsoftware/issrc/04328b96e3ff879fd3c8fcbc31c1031bb4fed8fa/Files/Languages/Unofficial/Latvian.isl)

Original translator credits are retained in each file. These modified versions use UTF-8, remove obsolete messages, add all missing 7.1.0 messages and correct placeholder errors. They are distributed under the Inno Setup license, included in the app and download notices. SFD-specific component messages are in `Setup.iss`.
